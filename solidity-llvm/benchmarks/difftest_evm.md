# Дифференциальное тестирование корректности трансляции (методология)

Цель: обосновать, что трансляция Solidity → размеченный LLVM IR **сохраняет семантику,
релевантную для анализа** (научная новизна диплома). Идея — сравнить вывод анализа поверх
нашего IR с поведением РЕАЛЬНОГО EVM на том же контракте.

Требует внешних инструментов (в текущем окружении отсутствуют): `solc` (компиляция в
EVM-байткод), `foundry`/`forge` + `anvil` (исполнение), либо `evmone`/`revm` (EVM-движок).

## Схема

Для каждого контракта корпуса:

1. **SCSA-вердикт:** `sca audit C.sol --json` → есть ли reentrancy (HIGH/MEDIUM) и в какой функции.
2. **Ground truth через EVM (Foundry):**
   - скомпилировать `C.sol` реальным `solc`, развернуть в `anvil`/форке;
   - для контрактов, помеченных reentrancy: сгенерированным нами PoC (`--poc`) ПРОГНАТЬ эксплойт
     (`forge test`) и проверить факт кражи (баланс жертвы упал, атакующего — вырос);
   - если PoC действительно крадёт → уязвимость подтверждена EVM-исполнением (истинный TP).
3. **Согласование:** SCSA-вердикт vs EVM-подтверждение → TP/FP/FN на РЕАЛЬНОМ исполнении, а не на
   ручных метках. Это сильнее, чем метки: корректность метода подтверждается запуском эксплойта.

## Что это даёт диплому

- **Обоснование корректности IR:** если PoC, построенный из нашего IR-анализа, реально крадёт в EVM —
  значит сохранённой в IR семантики достаточно для поиска реального бага (замыкание метод→эксплойт).
- **Независимая метрика:** precision/recall не по ручным меткам, а по факту эксплуатации в EVM.

## Скелет (когда инструменты доступны)

```bash
# 1. сгенерировать PoC из нашего анализа
sca audit Victim.sol --poc            # -> VictimReentrancyPoC.t.sol
# 2. подготовить Foundry-проект: src/Victim.sol (реальный solc-совместимый), test/PoC
forge test --match-test test_ReentrancyDrainsVictim -vv
# 3. PASS (баланс жертвы упал) => TP подтверждён EVM; FAIL => FP или PoC требует доработки
```

Сравнение со Slither (baseline «почему не Slither») — отдельный готовый скрипт
`compare_slither.sh` (нужен `slither` + `solc`).
