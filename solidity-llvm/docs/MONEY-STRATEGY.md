## 0. Вердикт одной строкой

**Детектор — не то, за что платят. А то, за что платят, детектор не видит.**
Текущий expected value хантинга этой тулзой ≈ 0 дохода (hit-rate 1/20, и та зацепка — «вопрос», не
payout). Как SaaS-продукт против Slither/Olympix преимущества нет. Единственный реальный путь к деньгам:
**тулза = приватный ускоритель воронки для МОЕГО хантинга**, сфокусированный на одном денежном классе
(ERC4626/inflation через инвариант-fuzz) + ниша bleeding-edge solc + скорость на свежих деплоях.

## 1. Почему детектор не платит (диагноз)

| Тулза ловит хорошо | Деньги в 2026? |
|---|---|
| Reentrancy / access-control на простых контрактах | ❌ Рынок вымыт. Overflow мёртв (0.8), OZ безопасен, CEI все знают. Протоколы гоняют Slither в CI **до** деплоя |
| Уникальные vs Slither | ❌ Это 3 файла SmartBugs — старые 0.4-паттерны, в живом 0.8 их нет |

| Где реально деньги (2025-26) | Видит тулза? |
|---|---|
| Share-inflation / ERC4626 first-depositor | ⚠️ `capability/g02 = miss`, но **InvariantGen scaffold ЕСТЬ** — единственная зацепка |
| Price-manipulation через balanceOf/oracle | ❌ `g04 = miss` (balanceOf исключён — FP-склонно) |
| Signature replay без nonce | ❌ `g03 = miss` |
| Fee-on-transfer / битый accounting | ❌ `g06 = miss` |
| Логика / экономика / cross-contract инварианты | ❌ Нужно понимание намерения — вне досягаемости автомата |

**Итог:** силён там, где денег нет (мёртвый рынок простой reentrancy), слеп там, где деньги есть
(экономические баги — собственный список `// expect: miss`). На единственном независимом бенчмарке
SCSA = бесплатный Slither (28/31 = 28/31).

## 2. Три асимметрии, которые МОГУТ заплатить (на чём фокус)

1. **Инвариант-харнессы на inflation/ERC4626** (`src/report/InvariantGen.cpp`). Единственный денежный
   класс, механически детектируемый, и он уже начат. `withdrawn <= deposited + donated` через forge-fuzz
   находит first-depositor кражу там, где Slither слеп. **Это настоящая новизна для денег — не reentrancy.**
2. **Bleeding-edge solc** (`benchmarks/build_solc_image.sh`). Upstream `ethereum/solc` встал на ~0.8.30;
   мы собираем 0.8.31–0.8.36 из офиц. бинарей. Свежие протоколы на новом компиляторе чужие тулзы не
   парсят — мы да. Узко, но реальная фора по времени.
3. **`--address` funnel** (Etherscan V2 + Blockscout + Sourcify + кастомные explorer L2/L3). Ценность не
   в детекторе, а в throughput: прогнал 200 верифиц. контрактов → 10 кандидатов → добил руками/Claude.

## 4. Стратегическая рамка

Нужны деньги *скоро* → режим **«я хантер с приватным инструментом»**, а не «я делаю продукт».
Самый короткий путь к первому доллару — ручной хантинг на правильных таргетах, где тулза ускоряет
воронку, а не пытается заменить аналитика. Тулза-как-продукт — потом, после доказанного личного payout.
