# SCSA — как пользоваться (простыми словами)

Это сканер безопасности смарт-контрактов. Он не просто говорит «тут подозрительно» (так умеет
бесплатный Slither), а **доказывает эксплойт рабочим PoC** — за это платят на багбаунти.

У тебя есть **две вещи**: сайт (для показа) и охота (для денег).

---

## 1. САЙТ — витрина для демо / защиты / инвесторов

Запуск (открой **новый** терминал, чтобы подхватился Node):
```
cd ~/diplom/web
npm run dev -- --port 5199 --strictPort
```
Открой в браузере: **http://localhost:5199/**
Остановить — `Ctrl+C` в терминале.

Что внутри:
- `/` — лендинг («Find the bug. Prove it.»)
- `/app` — консоль: список находок, деталь по каждой, раннер инвариантов, воронка, настройки.

Это для того, чтобы **показывать людям**. Денег сам по себе не приносит.

---

## 2. ОХОТА — это приносит деньги

### Главный цикл (запомни только его)
1. Берёшь **адрес контракта** из программы багбаунти (где — ниже).
2. В терминале:
   ```
   cd ~/diplom
   ./hunt_live.sh 0xАДРЕС
   ```
   (второй аргумент — сеть: 1=Ethereum, 56=BSC, 137=Polygon, 42161=Arbitrum, 8453=Base. По умолчанию 1.)
3. Смотришь итог внизу:
   - **`✅ КАНДИДАТ НА БАГ`** → пишешь мне: *«разбери находку по адресу 0x…»*. Я проверю, реальна ли,
     и доведу PoC.
   - **`чисто/мелочь`** → берёшь следующий адрес. Этот не наш.
4. Если PoC реальный → **несёшь на баунти** (кнопка Submit на Immunefi/Hats).

Чем больше адресов прогонишь — тем выше шанс. Это игра объёма.

### Где брать адреса (цели)
- **immunefi.com** → выбери программу → раздел **Assets in scope** → там адреса контрактов.
- Также: **hackenproof.com**, **hats.finance**, контесты **sherlock.xyz** / **code4rena** (миграция в Immunefi).
- **Фокус:** бери **новые / мелкие / неаудированные** протоколы и те, что на **Solidity 0.8**.
  Большие аудированные (Uniswap, 1inch) почти всегда пустые — не трать на них время.

## 3. Как командовать мной (Claude) — просто пиши по-русски

- «**проверь адрес 0x…**» — прогоню сканер и скажу, что нашлось.
- «**разбери находку по адресу 0x…**» — гляну исходник + факты, оценю реальна ли, соберу PoC.
- «**прогони инвариант против 0x…**» — если это vault (ERC4626), проверю на живом состоянии (округление и т.п.).
- «**прогони пачку адресов**» (дай список) — прогоню воронку, покажу выживших.
- «**покажи сайт**» — подскажу/запущу веб.

Мне не нужны технические детали — просто адрес или задача словами.

## 4. Шпаргалка команд (если хочешь сам, без меня)

```
# скан одного контракта по адресу (+ авто-PoC на HIGH)
./hunt_live.sh 0xАДРЕС [сеть]

# скан локального .sol файла
solidity-llvm/build/src/solidity-llvm -i файл.sol --audit

# пачкой по списку адресов (файл: по одному 0x-адресу в строке)
solidity-llvm/benchmarks/hunt_batch.sh --addrs список.txt
```
Ключи (Etherscan/RPC) уже лежат в `phase0/env.sh` — скрипты берут их сами.

## 5. Что это ищет (классы багов)

Находит и умеет доказывать: **reentrancy** (в т.ч. read-only), **кражу прав доступа**,
**произвольный внешний вызов**, **tx.origin**, а инвариантами (forge) — **округление**,
**first-depositor/share-inflation**, **неавторизованную эмиссию**, **solvency**. Это денежные классы,
которых не видит обычный сканер.

Честно: **логические/экономические баги, требующие понимания замысла протокола, — не гарантирует.**
Не притворяемся, что находим всё.

---

## 6. Если что-то не запускается

- **`npm: command not found`** → открой новый терминал (Node грузится через nvm из `~/.bashrc`),
  или выполни: `export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use --lts`.
- **`нужен ETHERSCAN_API_KEY`** → ключ в `phase0/env.sh`; если пусто — впиши свой (бесплатный на etherscan.io/apis).
- **RPC** уже переключён на бесплатную публичную ноду — трогать не надо.
- **порт 5199 занят** → возьми другой: `npm run dev -- --port 5200 --strictPort`.
